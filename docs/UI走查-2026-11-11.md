## 一、规范基线（先行结论）

项目已有**颜色**和**圆角**两组语义 token（`:root` 里 `--primary/--text/--surface/--radius` 等），但**没有间距 token，也没有字阶 token**，实际使用高度发散：

| 维度 | 现值 | 规范要求 | 状态 |
|---|---|---|---|
| 字号 | **31 档**（0.62rem ~ 3.2rem，列表页单页运行时就出现 12 档：9.92 / 11.52 / 11.84 / 12.8 / 13.12 / 13.6 / 13.92 / 14.08 / 14.4 / 15.2 / 16 / 18.4px） | 6~8 档成组（字号+行高+字重） | ✗ 发散 |
| 圆角 | token 4 档（18/12/8/50），另有**硬编码 7 档**（4/5/6/7/8/24/999px），`999px` 与 `--radius-pill:50px` 语义重复 | 3 档，超出回退最近一档 | ✗ 发散 |
| 间距 | 无 token；padding 出现 **12 种值**（2/3/4/5/6/8/9/10/16/18/20/24px），按 2px 步进 | 一套 4 或 8 的倍数梯度 | ✗ 缺 token |
| 颜色 | 语义 token 完整，暗色主题齐全 | 组件内不写色值 | △ 有 14 处 `#fff` 及零散 hex 绕过 token |
| 状态 | `:hover` 38 处、`:active` 3 处、`:disabled` 0 处 | 默认/悬停/按下/禁用/加载/错误 | ✗ 缺三态 |

**规范本身的问题单独列出，修复优先级低于阻塞项**，见第四节。

## 二、阻塞级（3 条，建议本版就修）

### B1 键盘焦点完全不可见
- **位置**：全局；`styles.css:314` `.chip-select select { outline: none }`，`.btn` 系列无 focus 样式
- **实测**：排序下拉 `outline: none 0px`、`box-shadow: none`；「筛选」按钮同样 `outline: none 0px`
- **规范**：焦点态必须可见，键盘可走完主流程（无障碍最低线）
- **影响**：Tab 键盲走，完全不知道焦点在哪；辅助技术用户无法操作整个应用
- **修复**：加全局 `:focus-visible { outline: 2px solid var(--primary); outline-offset: 2px }`，并删掉 `select` 上的 `outline: none`（或用 `:focus:not(:focus-visible)` 精确豁免鼠标点击）

### B2 主按钮白字对比度 2.32:1（要求 4.5:1）
- **位置**：所有 `btn-primary`（新建任务 / 保存 / 导出 / 生成今日日报），白字压 `--primary #3DBE9C`
- **实测**：`#FFFFFF on #3DBE9C = 2.32:1`；暗色下 `白 on #4DD4AC = 1.85:1`（更差）
- **影响**：最关键的 CTA 文字发虚，低视力/强光环境下读不出
- **修复**（两种，任选）
  - A. 实心按钮底色加深：`#268669`(4.47) 或 `#1F7A63`(5.22)，品牌绿仍留给图标与描边
  - B. 暗色主题改用深字：`#1A1824 on #4DD4AC = 9.44`，只改暗色一处即可

### B3 弹窗底部被视口切掉，保存按钮离屏
- **位置**：新建任务弹窗（同样问题见设置弹窗）
- **实测**：`.modal` 滚动 `716/643`；`.modal-body` 内容 `838` / 可见 `450`；**footer 底部 648 > 视口 643**
- **影响**：720p 窗口下「创建时间/完成时间」字段与底部按钮被截断，用户以为表单没这些项；滚动条又是整窗滚动，看不见提示
- **修复**：`.modal-content` 改 `display:flex; flex-direction:column; max-height:90vh`，`.modal-body` 独立 `overflow-y:auto`，footer 固定在卡片底部不参与滚动

## 三、影响体验（7 条）

### E1 空态文案不区分场景，没有出口
- 搜索「zzzz不存在」、筛选无结果时，仍显示「这里空空如也 / 点击「新建任务」开始记录你的第一件事」，唯一按钮是「新建任务」
- **问题**：场景错配 + 无「清除搜索/筛选」引导，用户只能自己回头找条件
- 另外：**日历视图没有空态**，周视图无任务时只有一片空白网格（`renderCurrentView` 里 `view !== 'calendar'` 才挂空态）
- **建议**：三套文案（真空库 / 搜索无结果 / 筛选无结果），后两者给「清除条件」按钮；日历给轻量空态

### E2 标签胶囊与元信息文字：小字 + 低对比
- `.badge.tag`：`color: #3DBE9C on #EBF9F5 = 2.15:1`，字号 0.68rem（10.9px）
- `.task-meta-time`（创建/完成时间）：`--text-3 #B0B0BF on #fff = 2.14:1`，字号 0.72rem（11.5px）
- **影响**：卡片上第二重要的信息（时间、分类）几乎看不清，暗色下 `#606072` 更是 2.53:1
- **建议**：标签改 `--primary-text` 深绿（`#1F7A63` on `#EBF9F5` = 4.82）；元信息从 `text-3` 提到 `text-2`（`#6A6A78` = 5.32）；`text-3` 只保留给纯装饰

### E3 看板三列共用一个滚动容器
- **实测**：内容高 49171px / 视口 583px；列 `overflow-y: visible`，`结办` 列自身 49013px 撑开整页
- **问题**：437 条任务下无法横向对照三列；滚到 结办 列底部时另两列早已滚走
- **建议**：`.kanban` 固定高度 + 每列 `overflow-y:auto`，列头吸顶

### E4 空列没有空态
- `待办 0` 列是一整块白色空白，只有列头数字
- **建议**：列内空态一行灰字「暂无待办」+ 可选「拖到这里」

### E5 工具栏在 ≤1100px 换行错位
- 1100px：第一行排到「导入 选择格式」，「导出」**单独掉到第二行最左**，右侧留大片空白（`toolbar` 高度 91px）
- 950px：搜索框压到 253px，placeholder「支持拼音首字母、模…」被截断；侧栏不收起仍占 237px
- **建议**：工具栏用 `flex-wrap` + `gap` 并允许搜索框 `min-width: 220px`；窄屏把「导入/导出/多选」收进「更多」菜单；侧栏 <1080px 自动折叠

### E6 仪表盘 7 张指标卡塞进 4 列网格
- **实测**：`grid-template-columns` 4 列 × 2 行，卡片 7 张 → 第二行右侧空 1 格
- **建议**：改 3 列（3×3 少一格）或 7 张改为 4+3 分组的两个网格，视觉上明确分组

### E7 浮动底部导航遮挡正文
- **实测**：滚到 300px 时，导航矩形 (556~623) 下有 **2 张任务卡**被覆盖；内容底部虽有 100px padding，但滚动过程中始终压着内容
- **建议**：滚动时导航降低不透明度/缩小，或改为贴底固定栏（内容区 `padding-bottom` 与栏高等值），彻底不叠内容

## 五、设计规范本身的问题（单列，不混入实现问题）

### 对比度实测（WCAG 2.1，正文需 ≥4.5，大字 ≥3.0）

| 用途 | 前景 / 背景 | 实测 | 判定 |
|---|---|---|---|
| 正文 | `#2D2D3A` / `#FFF` | 13.57 | ✓ |
| 次要文字 `--text-2` | `#7A7A8C` / `#FFF` | **4.21** | ✗ 差 0.29 |
| 弱化文字 `--text-3` | `#B0B0BF` / `#FFF` | **2.14** | ✗ |
| 弱化文字在 `surface-3` | `#B0B0BF` / `#F0ECF9` | **1.84** | ✗ |
| 主色作文字 | `#3DBE9C` / `#FFF` | **2.32** | ✗ |
| 白字在主色（按钮） | `#FFF` / `#3DBE9C` | **2.32** | ✗ |
| 白字在 warning | `#FFF` / `#F5A623` | **2.03** | ✗ |
| 白字在 danger | `#FFF` / `#FF6B6B` | **2.78** | ✗ |
| 白字在 info | `#FFF` / `#5BA4CF` | **2.74** | ✗ |
| 暗-弱化文字 | `#606072` / `#242233` | **2.53** | ✗ |
| 暗-白字在主色 | `#FFF` / `#4DD4AC` | **1.85** | ✗ |

**结论**：不是个别组件的问题，是**整套 token 的明度取值偏浅**。建议一次性调整 token 而不是逐个打补丁：

```css
--text-2: #6A6A78;   /* 白底 5.32 / surface-3 底 4.58 */
--text-3: #84849A;   /* 3.65，仅用于装饰，不再承载正文信息 */
--primary-text: #1F7A63;  /* 主色文字/链接，白底 5.22 */
--primary-btn: #268669;   /* 实心按钮底，白字 4.47；或 #1F7A63 = 5.22 */
/* 暗色 */
--text-3: #8A8A9C;   /* 暗底 4.58 */
--primary-btn: #4DD4AC; /* 配深字 #1A1824 = 9.44 */
```

### 字阶建议（收敛 31 → 7 档）

| token | 值 | 用途 |
|---|---|---|
| `--fs-xs` | 12px / 1.4 | 标签、角标 |
| `--fs-sm` | 13px / 1.5 | 元信息、说明 |
| `--fs-base` | 14px / 1.6 | 正文、任务标题 |
| `--fs-md` | 16px / 1.5 | 弹窗标题 |
| `--fs-lg` | 20px / 1.4 | 页面标题 |
| `--fs-xl` | 28px / 1.2 | 指标数字 |
| `--fs-2xl` | 40px / 1.1 | 空态大数字（如需） |

现存的 9.92px / 11.52px / 11.84px 三等都属于「没有档位可落」的产物，收敛后自然消失。
