# 知行 (Zhixing) · 任务与日报工作台

一个功能完整的桌面任务与日报管理应用，使用 Electron + 原生 JavaScript + HTML + CSS 开发。支持列表 / 看板 / 日历三视图、批量操作、子任务、标签分类、多清单、统计图表、每日工作日报、自动备份与本地加密。应用图标与界面均采用飞书（Lark）网页版设计语言，图标全部内联 SVG 离线可用。

## 功能特性

### 核心任务管理
- ✅ **增删改查**：添加、编辑、复制、删除任务
- ✅ **三态流转**：待办 → 在办 → 结办，并留痕创建 / 开始 / 完成时间
- ✅ **批量操作**：多选后批量改状态、改优先级、删除、归档
- ✅ **子任务与备注**：任务可拆解为子任务清单，支持长文本备注
- ✅ **置顶 / 归档**：重要任务置顶，完成任务归档不打扰
- ✅ **优先级强视觉**：高 / 中 / 低三级差异化配色，临近到期自动提权，悬浮快捷改优先级
- ✅ **精确截止**：支持精确到时分的截止时间，逾期 / 临期高亮
- ✅ **周期重复**：支持每日 / 每周 / 每月重复任务，完成后自动生成下一次

### 视图与交互
- ✅ **三视图切换**：列表视图、看板视图（拖拽流转状态）、日历视图
- ✅ **快捷键**：Ctrl+N 新建、Ctrl+F 搜索、Esc 关闭弹窗
- ✅ **卡片悬浮操作**：鼠标悬浮显示快捷操作按钮
- ✅ **移动端适配**：窄屏侧栏抽屉 + 悬浮新增按钮
- ✅ **操作反馈**：危险操作二次确认，Toast 即时提示，友好空状态

### 搜索、筛选与排序
- ✅ **多条件组合筛选**：状态 + 优先级 + 标签 + 日期范围 + 关键词
- ✅ **拼音首字母 / 模糊搜索**：离线拼音首字母匹配，无需联网
- ✅ **保存筛选**：常用筛选条件可命名保存，一键复用
- ✅ **组合排序 + 手动拖拽**：按日期 / 优先级排序，或手动拖拽自定义顺序（置顶优先）

### 标签、分类与多清单
- ✅ **自定义标签**：任意打标签，按标签筛选
- ✅ **多清单管理**：不同项目 / 场景分清单管理

### 工作日报
- ✅ **日报撰写**：Markdown 编辑器，按日撰写工作日报，支持历史记录按日期检索
- ✅ **一键生成**：根据当日任务自动汇总「今日完成 / 进行中 / 待处理 / 逾期未完成 / 明日计划」，生成日报草稿
- ✅ **历史管理**：按日期查看、编辑、删除历史日报，侧栏「写日报」一键进入
- ✅ **导出归档**：日报可导出为 Markdown 文件，便于归档与同步

### 统计与数据能力
- ✅ **统计仪表盘**：完成率、今日 / 本周、逾期等多维指标
- ✅ **可视化图表**：优先级分布环形图 + 近 7 日完成趋势折线图 + 本周每日完成柱状图 + 标签分布条形图，附效率分析
- ✅ **自动备份**：每日自动备份，保留最近 7 天，可手动备份 / 还原
- ✅ **本地加密**：可选 AES-256-GCM 加密本地数据，密码解锁
- ✅ **导入 / 导出**：JSON / CSV / TXT / Markdown，支持筛选后导出、导入预览与冲突处理

### 效率与个性化
- ✅ **系统通知**：到期 / 逾期提醒、每日待办提醒
- ✅ **智能识别**：输入"明天""紧急"等关键词自动填充日期 / 优先级
- ✅ **输入联想**：根据历史任务联想补全
- ✅ **明暗主题**：浅色 / 深色主题切换
- ✅ **列表密度**：舒适 / 紧凑两种密度

### 性能与稳定性
- ✅ **全量渲染 + 防抖节流**：任务列表全量渲染（卡片高度不一，固定行高的虚拟滚动会错位，已弃用）；搜索、筛选等高频输入均做防抖处理
- ✅ **容错机制**：导入异常提示、存储校验、原子写入防止数据损坏

## 安装和运行

### 前提条件
- Node.js (v16.x 或更高版本)
- npm 或 yarn

### 安装步骤

```bash
git clone <repository-url>
cd electron-todo-list
npm install
npm start
```

## 数据存储

数据保存在用户数据目录下，按职责拆分为多个文件：

| 文件 | 用途 |
| --- | --- |
| `todoList.json` | 任务数据（可加密） |
| `reports.json` | 工作日报数据（可加密） |
| `settings.json` | 应用设置（主题、密度等） |
| `lists.json` | 多清单定义 |
| `savedFilters.json` | 保存的筛选条件 |
| `crypto.meta.json` | 加密元数据（盐值等，不含明文密码） |
| `backups/` | 每日自动备份目录（保留 7 天） |

写入采用「临时文件 + 重命名」的原子写入方式，避免中途崩溃损坏数据。开启加密后，任务数据以 `ENC1:iv:tag:data` 格式经 AES-256-GCM 加密存储，密钥由密码通过 scrypt 派生。

## 任务数据格式

```json
{
  "id": "1620000000000",
  "content": "完成项目开发",
  "status": "pending",
  "priority": "high",
  "date": "2025-11-22",
  "startDate": "",
  "dueTime": "18:00",
  "listId": "default",
  "tags": ["工作", "重要"],
  "note": "记得同步给团队",
  "subtasks": [{ "id": "s1", "text": "写文档", "done": false }],
  "pinned": false,
  "archived": false,
  "order": 0,
  "repeat": { "type": "none", "interval": 1 },
  "createdAt": "2025-11-22T08:00:00.000Z",
  "startedAt": null,
  "completedAt": null
}
```

> `repeat.type` 取 `none | daily | weekly | monthly | custom`；`custom` 时 `interval` 为间隔天数。

## 应用打包指南

```bash
npm run dist:win        # Windows
npm run dist:mac        # macOS
npm run dist:linux      # Linux
npm run dist            # 所有平台
npm run dist:win:quick  # 快速打包（Windows）
```

打包输出位置：
- **Windows**：便携版 `dist/win-unpacked/知行.exe`，安装版 `dist/知行 Setup.exe`
- **macOS**：`dist/知行.dmg`
- **Linux**：`dist/知行.AppImage`、`dist/zhixing_1.0.0_amd64.deb`
